How to read the numbers

  • A's higher correctness is not a real win. A and C were scored on slightly different sets of questions (one of A's items failed). On the questions both were scored on, their correctness is the same (see docs/error-analysis.md).
  • Recall counts only the exact gold quote. The same figure is often in a press release, a 10-Q and a transcript, so an answer can be right while recall marks the quote as missed.
  • The live config was chosen after the test run. The API used config D before; it was switched to C because D's threshold wrongly declined more answerable test questions. That choice used these test results, so the live row is a slightly optimistic estimate. No setting was re-tuned and nothing was re-run.
  • Small sample. One question changes a percentage by several points.
  • The judge is an LLM. Its rubric was revised after comparing it with human labels on the same dev answers it is measured on below, so the agreement is optimistic. It is also too generous on multi-quarter answers with shifted quarter labels.

Metric definitions

Recall@k (all / any quote)
Share of answerable questions where every gold quote (or at least one) is in the retrieved chunks.
MRR
Mean of 1 / rank of the first retrieved chunk that contains a gold quote.
Period coverage
For multi-quarter questions: share of the required quarters with at least one retrieved chunk.
Faithfulness / fully faithful
The judge splits each answer into claims and checks each against the cited sources. Score = supported / total; "fully faithful" = answers with every claim supported.
Citation precision
Share of citations whose source actually supports the sentence it is attached to (judge).
Number grounding
Share of numbers in answers that appear in the cited sources (automatic check, no judge).
Correctness
The judge compares the answer with the reference answer on a 1 to 5 rubric.
Abstention precision / recall
Of the questions the system declined, how many really were unanswerable / of the unanswerable questions, how many it declined.
False abstention
Share of answerable questions the system wrongly declined.
Latency, cost
Time per question (50th and 95th percentile) and model cost per question from token counts.
