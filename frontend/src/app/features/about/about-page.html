About EarningsLens

EarningsLens answers questions about company earnings using only the companies' own documents: earnings call transcripts, earnings press releases and 10-Q and 10-K filings. Every claim in an answer links to the passage it came from, and when the documents do not contain the answer, it says so instead of guessing.

Design decisions

Answers only from sources
The model sees numbered passages and must cite them. The server removes citations to sources that do not exist and flags numbers that do not appear in the cited passages.
Hybrid search, per quarter
Vector search finds passages with similar meaning, keyword search finds exact terms and figures, and the two rankings are merged with reciprocal rank fusion. A question about several quarters searches each quarter separately so none is crowded out.
A parser, not an LLM, for filters
Company names and fiscal quarters are read from the question by deterministic rules, so the same question always searches the same documents and the behaviour can be tested.
Saying "I don't know"
When a quarter is not in the corpus, or the model finds no evidence, the app declines and says what it searched, instead of guessing.
Measured, not claimed
Four configurations were compared on a held-out test set, used once after all settings were frozen, with an LLM judge checked against human labels. The Evaluation page shows those results and their caveats.
Plain building blocks
Java with Spring Boot and Spring AI, PostgreSQL with pgvector, Angular. No agent frameworks; the retrieval SQL is written by hand so every step can be explained.

Known limitations

  • It covers only the companies and quarters listed on the Corpus page, and only US filers (10-Q and 10-K).
  • Answers can still be wrong or incomplete. Open the cited sources before relying on any figure.
  • Product names (for example a single app or device) are not mapped to their company, and phrases like "end of last year" are not turned into a quarter, so such questions may search the wrong quarters.
  • Source text is passed to the model as data, but prompt injection hidden in a document cannot be ruled out.
  • Questions are rate limited per visitor and per day to keep the demo's costs down.
  • Not investment advice.
